# Practical 8 – Inheritance & Method Overriding

**Subject:** Object-Oriented Programming with Java  
**Practical No.:** 8  
**Topic:** Inheritance, Method Overriding & Runtime Polymorphism  
**Language:** Java 26  
**Author:** Rajesh Maurya

## 📌 Overview

This practical demonstrates important Object-Oriented Programming (OOP) concepts in Java through three programming questions. It covers inheritance, method overriding, and runtime polymorphism using real-world examples.

## 🎯 Objectives

- Understand inheritance and parent-child class relationships.
- Implement method overriding using the `@Override` annotation.
- Demonstrate runtime polymorphism.
- Create and use objects of different classes.
- Apply OOP concepts to practical programming problems.

## 📝 Questions Covered

### Question 1: Animal Hierarchy

Create a parent class `Animal` and child classes `Dog`, `Cat`, and `Cow`.

**Concepts covered:**
- Inheritance using `extends`
- Method overriding
- Parent-child class relationships
- Runtime polymorphism

### Question 2: Shape Hierarchy

Implement a shape hierarchy to demonstrate inheritance and method overriding. Use the appropriate shape classes and overridden methods as defined in the program.

**Concepts covered:**
- Inheritance
- Method overriding
- Classes and objects
- Runtime polymorphism

### Question 3: Vehicle Hierarchy

Create a parent class `Vehicle` with common attributes such as `brand`, `model`, and `speed`. Implement child classes `Car`, `Bike`, and `Bus` that override the `start()` and `displayInfo()` methods.

**Concepts covered:**
- Inheritance
- Method overriding using `@Override`
- Runtime polymorphism
- Reusability of code
